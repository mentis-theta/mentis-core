# ADR 0002: Busca Híbrida

## Status
Aprovado

## Contexto
Busca vetorial pura falha em termos clínicos muito específicos (ex: DSM-5-TR 296.2).

## Decisão
Utilização de RRF (Reciprocal Rank Fusion) mesclando Keyword Search com Vector Search.
